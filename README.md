
# WorkerSafetyWatch
### Galaxy Watch 기반 작업자 안전 모니터링 시스템

## 1. 프로젝트 개요

본 프로젝트는 산업 현장 작업자의 안전 상태를 모니터링하기 위한 갤럭시 워치 기반 애플리케이션 개발 프로젝트이다.

Galaxy Watch5의 심박수 및 피부온도 센서를 활용하여 작업자의 생체 데이터를 수집하고, 5분 또는 10분 간격으로 스마트폰 애플리케이션에 전달하는 것을 목표로 한다.

워치에서 측정한 데이터는 스마트폰 앱에서 확인할 수 있도록 구성하며, 향후 서버 및 데이터베이스와 연동하여 작업자의 상태를 분석하는 안전관리 시스템으로 확장할 계획이다.

현재는 워치 앱의 기본 구조와 사용자 인터페이스를 구현하였으며, 실제 센서 측정과 기기 간 통신은 추후 실기기 검증을 진행할 예정이다.

## 4. 주요 개발 내용

### 4.1 워치 애플리케이션 개발

Android Studio에서 Wear OS 기반 워치 애플리케이션을 구성하였다.

기존 프로젝트에 Samsung Health Sensor SDK를 추가하고, 심박수 및 피부온도 데이터를 수집하기 위한 Kotlin 코드를 작성하였다.

현재 앱은 측정 시작과 종료, 측정 주기 선택 및 데이터 표시를 위한 기본 구조를 포함하고 있다.

### 4.2 심박수 및 피부온도 측정

Samsung Health Sensor SDK를 활용하여 다음 데이터를 수집하도록 코드를 구성하였다.

- 심박수(Heart Rate): BPM 단위 측정
- 손목 피부온도(Skin Temperature): °C 단위 측정
- 측정 시간 및 유효 데이터 수

수집된 데이터는 일정 시간 단위로 정리되며, 심박수는 해당 구간의 평균값을 계산하도록 구성하였다.

유효한 측정값이 없는 경우 임의의 수치를 생성하지 않고 `--`로 표시하도록 설계하였다.

현재 실제 센서 데이터 수신 여부는 검증 전 상태이다.

### 4.3 데이터 전송 기능

측정 주기는 사용자가 5분 또는 10분 중 선택할 수 있도록 구성하였다.

설정된 시간에 따라 측정 데이터를 정리하고, Google Wearable Data Layer API를 이용하여 스마트폰으로 전달하는 코드를 작성하였다.

스마트폰 앱에서는 수신한 데이터를 화면에 표시하도록 기본 구조를 구성하였다.

현재 전송 코드는 작성되었으나 실제 워치와 스마트폰 사이의 통신 검증은 진행하지 않았다.

### 4.4 사용자 인터페이스 구현

Figma를 이용해 워치 애플리케이션의 화면을 디자인하고, Android XML 레이아웃으로 구현하였다.

현재 화면 구성은 다음과 같다.

1. 측정 시작 화면
   - START 버튼
   - 5분 / 10분 측정 주기 선택

2. 심박수 화면
   - 현재 심박수 표시
   - BPM 단위 표시

3. 피부온도 화면
   - 손목 피부온도 표시
   - °C 단위 표시

4. 송신 오류 안내 화면
   - 통신 오류 발생 시 사용자에게 알림
   - 자동 오류 감지 및 화면 전환 기능은 추후 보완 예정

워치의 원형 디스플레이에 맞도록 화면 크기, 글자 및 버튼의 배치를 조정하였다.

## 6. 개발 및 테스트 진행 현황

### 완료한 작업

- Android Studio 개발환경 구성
- Gradle 프로젝트 동기화
- Samsung Health Sensor SDK 라이브러리 연결
- 워치 앱 및 스마트폰 앱 기본 코드 구성
- Figma 디자인 기반 워치 UI 구현
- 원형 워치 화면에 맞춘 XML 레이아웃 수정
- Android Studio 프로젝트 빌드 성공
- Wear OS 4(API 33) 에뮬레이터 생성
- 워치 앱 에뮬레이터 설치 및 실행 성공

### 추가 검증이 필요한 작업

- 실제 Galaxy Watch5 심박수 측정
- 실제 피부온도 데이터 수신
- 5분 / 10분 주기 전송 동작 확인
- 워치와 스마트폰 간 데이터 통신
- 송신 실패 감지 및 오류 화면 자동 전환
- 화면 종료 및 백그라운드 상태에서의 동작
- 배터리 소모 및 장시간 안정성 검증

현재까지 Android Studio에서 빌드 및 에뮬레이터 실행에 성공하였으나, Samsung Health Sensor SDK의 실제 센서 동작은 검증하지 않았다.

## 7. 향후 개발 계획

### 7.1 스마트폰 앱 연동

워치에서 전송한 심박수 및 피부온도 데이터를 스마트폰 앱에서 수신하고 표시하는 기능을 실제 기기로 검증할 예정이다.

### 7.2 송신 오류 처리

스마트폰과의 연결이 끊기거나 데이터 전송에 실패했을 때 오류 상태를 감지하고, 워치 화면에 자동으로 경고를 표시하는 기능을 추가할 예정이다.

### 7.3 백그라운드 동작 개선

앱 화면이 꺼진 상태에서도 데이터 측정과 전송이 안정적으로 이루어지는지 검증하고 필요한 기능을 보완할 예정이다.

### 7.4 서버 및 데이터베이스 연동

스마트폰으로 전달된 데이터를 서버에 저장하고, 향후 작업자별 생체 데이터 조회 및 상태 분석 기능을 개발할 예정이다.

---

## 8. 개발 시 참고사항

- 본 프로젝트는 현재 개발 및 테스트 단계의 MVP이다.
- 실제 센서 측정과 스마트폰 통신은 실기기 검증이 필요하다.
- 피부온도는 손목 피부온도로, 심부체온과 다르다.
- 본 애플리케이션은 의료적 진단이나 응급상황 판정을 보장하지 않는다.
